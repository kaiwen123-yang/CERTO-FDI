# Dataset License and Access Checklist

对每个数据集逐项确认：

- [ ] 官方数据页面与论文一致；
- [ ] 版本/DOI/commit 已冻结；
- [ ] 研究用途许可允许下载和计算；
- [ ] 是否限制商业使用；
- [ ] 是否允许派生数据；
- [ ] 是否允许在 review package 中放小样例；
- [ ] 是否要求引用数据 DOI 与论文；
- [ ] 是否包含个人/敏感数据；
- [ ] 是否允许公开 checkpoint；
- [ ] 原文件 checksum；
- [ ] 解压后 manifest；
- [ ] 数据不得提交 Git；
- [ ] 任何许可不确定性记录并阻塞再分发，不阻塞本地研究分析。
