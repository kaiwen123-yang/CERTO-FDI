# 控制器、完整观测与缺测：一个物理一致的一阶例子

2026-10-07。工具命题，不单独声称新颖性。它用于后续M1桥梁：同时改变信号与噪声的控制器，在完整记录下保持信息，却可在删除输出后改变信息损失。

## 系统与共同输入

固定植物系数λ，以作用于第j步的因果状态反馈u_j=−Kx_(j−1)控制x_j=λx_(j−1)+u_j+d^h+w_j，闭环c=λ−K。设|c|≤c_bar<1，x_0=0已知，且

\[
x_j=cx_{j-1}+d^h+w_j,
\qquad w_j\overset{iid}{\sim}N(0,q),\quad q>0,
\]

H0取d^0=0，H1取已知常数d^1=d。外部输入d、创新强度q、H和保留日历固定；只比较已知控制器K。没有额外测量噪声，本例暂不含健康漂移。

## 命题1：完整记录的信息与控制器无关

令F_c为对角元1、下三角元(F_c)_(ij)=c^(i−j)的H×H矩阵。完整输出为x=F_c(d1+w)，两点均值差dF_c1，协方差qF_cF_cᵀ。因F_c可逆，

\[
G_{full}=\frac12(dF_c1)^\top(qF_cF_c^\top)^{-1}(dF_c1)
=\frac{Hd^2}{2q}.
\]

可逆映射x_j→x_j−cx_(j−1)共同且已知，把整个实验还原为独立创新观测。对任意共同输入均值集合也一样：每个检验可以与映射双向复合，逐参数size和power均保持，故整个复合风险保持。若c依赖未知参数，或只保留部分输出，该推理不能直接使用。

## 命题2：同一内部缺测的损失依赖闭环c

保留x_ℓ与x_(ℓ+m)，删除中间k=m−1个输出。由系统递推，

\[
x_{ℓ+m}=c^m x_ℓ+dA_m+\sum_{r=0}^{m-1}c^r w_{ℓ+m-r},
\quad A_m=\sum_{r=0}^{m-1}c^r,
\quad B_m=\sum_{r=0}^{m-1}c^{2r}.
\]

完整的m次条件观测信息为md²/(2q)。删除后的一次条件观测信息为d²A_m²/(2qB_m)。其他相邻transition保持相同，故精确损失为

\[
\boxed{ΔG_c(k)=\frac{d^2}{2q}\left[m-\frac{A_m^2}{B_m}\right].}
\]

不同保留间隔的独立创新和给出相加公式，保留初始x0时同样适用于首个观测间隔。Cauchy–Schwarz给A_m²≤mB_m；m>1且c≠1时严格不等，故损失为正。固定m、c→1时趋零，但c=1不属于统一稳定类；不能借此宣称最优控制器必在未允许的边界。

k=1时，κ_c:=2ΔG_c q/d²为

| c | κ_c |
|---:|---:|
| 0 | 1 |
| 1/2 | 1/5 |
| −1/2 | 9/5 |

这与stationary AR(1)的归一化gap系数一致：steady mean为d/(1−c)，steady variance为q/(1−c²)，两者随c一起改变。完整记录主信息仍是d²/q每槽。只改变噪声相关而固定输出均值会破坏这个物理比较。

## 与研究主线的接口及限制

该例证明删输出与可逆滤波的顺序不可交换，给控制进入诊断缺测代价的明确机制。它没有证明带漂移的最优日历，也不包含任务移动期间的已知回归、测量噪声、饱和或跟踪预算。实际诊断器若还能取得每个x_j对应的控制命令或内部状态，缺测信息可能被补回；必须按实际可读接口重新定义实验。

下一步将d^h替换为相同物理系统中的a_j+s_j b^h_j，并明确移动期s_j、所有创新与初始状态；然后分析删除后的健康像和加权跨gap约束。不能把本例的κ直接代入M0主定理而省略均值和健康路径映射。
